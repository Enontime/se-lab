## FINAL-045-001：合法长商品名撑宽预约详情弹窗

**复现**：卖家创建合法的 1000 个连续 `X` 名称商品，管理员审核通过；买家预约后，买家/卖家打开预约详情。在 1440/390/320px，原版 `.modal-body` 内第一条 `dd` 会显示成几千像素长的一行（补充 QA 320px 报告 `clientWidth=283`、`scrollWidth=7797`）。

**原因**：此前的 `overflow-wrap:anywhere` 仅设置在商品公开详情的 `.detail-info` 下，预约弹窗使用 `.modal .definition dd`，没有继承该规则。

**修改**：
- `.modal .definition dd`、`.modal-body`、`.modal-head h2`、历史内容设置 `min-width:0` 与 `overflow-wrap:anywhere`。
- 320px 小屏采用较窄的术语列和适当内边距，保持信息内容可阅读。
- 不使用 `overflow-x:hidden`、`text-overflow:ellipsis`、服务端截断，保留数据库返回的全部合法文本；允许纵向滚动。

## FINAL-045-002：关闭弹窗后焦点丢失

**复现**：键盘将焦点移动到买家/卖家列表的“详情”，按 Enter 打开，随后按 Escape 或点击“关闭”。原版关闭后 `document.activeElement` 为 `BODY`，直接再按 Enter 无法操作原详情。

**原因**：全局点击处理器在异步请求期间禁用触发按钮；原生 dialog 的自动恢复焦点无法可靠地恢复到该按钮。关闭时只移除 dialog，没有主动管理焦点。

**修改**：
- 打开弹窗前显式将触发按钮传入 `showBooking` / `showHistory` / `modal`。
- `close` 事件统一处理点击关闭、Escape 和背景点击，移除弹窗后把焦点恢复到原按钮。
- 恢复前检查按钮存在、未禁用、身份及路由视图仍匹配，且没有其他新弹窗打开；`preventScroll` 避免焦点恢复时页面跳跃。
- 新路由渲染时主动关闭旧弹窗，不让旧的预约详情内容覆盖另一页面，也不会把焦点恢复给旧页面。
