## v0.4 网页实现（2026-11-10，实验三开发记录；非实验报告）

- 辅助场景：检查实验二提交版 U1～U7 的 PlantUML 与 v0.3 后端状态规则、事务流程的对应；据 UI-01～UI-11 静态原型实现真实可操作网页。
- 用户重要要求：真实功能优先；代码非 GUI 至少 1500 行；不绕过 REQ-005 的待确认边界；代码与设计一致。
- 发现并修正：v0.3 附带 U1 源文件的布局与实验二提交版本不同，U6/U7 PNG 也非字节相同；v0.4 直接恢复实验二全部原始 PNG 和 puml。
- 前端设计：Jinja2 首页、原生 CSS、原生 JS Hash 导航，按普通用户与管理员显示界面；沿用现有 REST API，业务操作继续由服务层验证权限、状态与事务。
- 实现过程发现：快速导航时旧页面的异步查询可能覆盖新页面，在展示结果前添加路由检查以避免该竞态。
- 实际验证：原 97 项业务测试在本地再次通过；JS 语法检查通过；使用 Chromium + 模拟接口完成商品浏览、用户登录、预约、发布、我的统计和管理员审核/统计/日志页面冒烟。真实 Flask/UI HTTP 测试需在 Windows 执行。
- 局限：本版保留实验二视觉体系与交互入口，但 CSS 商品示意图与原型中的静态插画并不逐像素一致；尚未实施生产环境 HTTPS、CSP、真实图片上传或完整前端自动化 E2E CI。
